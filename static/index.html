ผลประเมินเบื้องต้น

กรอกข้อมูลแล้วกดคำนวณเพื่อดูผล

อัตราส่วนการใช้พิกัดตัวอย่าง

ผลนี้ไม่ประเมินลม การตั้งขา configuration ความแข็งแรงแผ่นรอง หรือยืนยันเอกสารรับรอง

ก่อนนำไปทบทวน

เตรียม Load chart ของผู้ผลิตที่ตรงกับเครื่องจริง configuration และข้อมูลแรงกดขา รวมถึงผลประเมินดินและมาตรการงานยก

วิธีเพิ่มแอปบนหน้าจอ

iPhone: เปิดด้วย Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
Android / คอมพิวเตอร์: ใช้เมนูติดตั้งแอปของเบราว์เซอร์ (ต้องเปิดผ่าน HTTPS)

ข้อมูลจะหายได้หากล้างข้อมูลเบราว์เซอร์ ควรส่งออกไฟล์สำรองเป็นระยะ ร่างบันทึกเฉพาะเบราว์เซอร์นี้ ไม่ซิงก์ข้ามเครื่อง คำนวณ บันทึกร่าง และพิมพ์รายงานในเครื่องได้โดยไม่ส่งข้อมูลแผนไปยังเซิร์ฟเวอร์ หลังเปิดแอปครั้งแรกและเตรียมออฟไลน์สำเร็จ
